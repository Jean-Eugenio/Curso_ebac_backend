# Projetos Back-end Java — EBAC

Repositório com projetos desenvolvidos durante minha formação em **Desenvolvimento Full Stack Java pela EBAC**, reunindo diferentes aplicações e exercícios práticos voltados ao desenvolvimento back-end.

Os projetos abrangem desenvolvimento com Java, APIs REST, persistência de dados, bancos relacionais e NoSQL, testes, arquitetura em camadas e microserviços.

---

## ⭐ Principais projetos

### Módulo 42 — Sistema de Microserviços para Gerenciamento de Vendas

**Java · Spring Boot · MongoDB · Spring Cloud · OpenFeign · REST**

Projeto desenvolvido utilizando arquitetura de microserviços, com serviços independentes para gerenciamento de clientes, produtos e vendas.

**Principais conceitos:** microserviços, APIs REST, Spring Cloud Config, comunicação entre serviços e persistência com MongoDB.

[→ Ver projeto — Módulo 42](https://github.com/Jean-Eugenio/projetos-backend-java-ebac/tree/Exercicio_modulo_42)

---

### Módulo 35 — Sistema de Gerenciamento de Vendas com JPA e Hibernate

**Java · JPA · Hibernate · PostgreSQL · JUnit**

Projeto focado em persistência de dados e gerenciamento de clientes, produtos e vendas, utilizando arquitetura em camadas, padrão DAO e camada de Service.

**Principais conceitos:** JPA, Hibernate, ORM, PostgreSQL, CRUD, arquitetura em camadas e testes automatizados.

[→ Ver projeto — Módulo 35](https://github.com/Jean-Eugenio/projetos-backend-java-ebac/tree/Exercicio_modulo_35)

---

### Módulo 30 — JDBC e PostgreSQL

**Java · JDBC · PostgreSQL**

Projeto desenvolvido para aplicação prática de acesso e manipulação de dados utilizando Java, JDBC e PostgreSQL.

[→ Ver projeto — Módulo 30](https://github.com/Jean-Eugenio/projetos-backend-java-ebac/tree/Exercicio_modulo_30)
